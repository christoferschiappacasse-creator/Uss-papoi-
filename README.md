# Panel de ventas — Programación 2

Este proyecto utiliza Streamlit, Pandas y Plotly para analizar `ventas.csv`, que contiene `fecha;color;unidades`.

## Publicación en Streamlit Community Cloud

1. Subir `app.py`, `requirements.txt` y `ventas.csv` a la raíz del repositorio en GitHub. `README.md` es opcional.
2. Usar la rama `main` y el archivo principal `app.py` en Streamlit Community Cloud.
3. La aplicación leerá `ventas.csv` automáticamente y permitirá cargar otros archivos desde la barra lateral.

No subir carpetas `venv` ni archivos `.zip` como sustituto de estos archivos.

**Nota:** unidades vendidas no significa ingresos monetarios; no hay precios en el CSV.
